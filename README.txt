ORIGINAL IMAGE ASSETS
======================
The current Google Sites pages expose Google-hosted image URLs, but those image endpoints returned HTTP 403 to the retrieval service used to build this package. I therefore did NOT substitute random/AI images.

Put the Trust's original images in this folder and update the image paths in the HTML files.
Recommended folders:
  images/logo/
  images/board/
  images/projects/
  images/gallery/
  images/bank/

Important: verify that every photo is owned/licensed by the Trust before publishing.
