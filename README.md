# Khwajja Gharib Nawaz Trust — Official Website

Modern, lightweight static website ready for **GitHub Pages**.

## Go live in 3 steps

1. Create a new GitHub repository (e.g. `kgn-trust` or `username.github.io`).
2. Upload **all files and folders** from this `kgn-trust` directory to the root of the repo (or to the `docs` folder / `gh-pages` branch).
3. In the repo: **Settings → Pages → Source** → Deploy from branch `main` (root) or `docs` folder.

Your site will be available at:  
`https://YOUR_USERNAME.github.io/REPO_NAME/`  
(or `https://YOUR_USERNAME.github.io/` if using a user/organization site).

## Features

- Original homepage header: founder image background, founder name, location
- Same page structure as the previous site
- Modern dark theme with gold accents
- CSS 3D card hover effects & subtle hero animation
- Fully responsive, no build tools required
- Lightweight — pure HTML/CSS/JS

## Custom domain (optional)

Add a `CNAME` file in the root with your domain (e.g. `www.kgntrust.org`) and configure DNS as per GitHub Pages docs.
