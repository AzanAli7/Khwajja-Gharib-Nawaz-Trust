# Khwaja Gharib Nawaz Trust — Website

Updated GitHub Pages website for Khwaja Gharib Nawaz Trust.

## Files
- `index.html` — website structure and About Us content
- `style.css` — responsive design, animations and 3D-style hero
- `script.js` — navigation, reveal animations and scroll progress

## GitHub Pages
Upload/replace these three files in the repository root and keep:
Settings → Pages → Deploy from a branch → `main` → `/(root)`.

Verify the Trust's contact details, WhatsApp number, donation/bank details, social links and real gallery images before using them publicly.
